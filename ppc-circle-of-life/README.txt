Consignes pour lancer la simulation :

Dans un premier terminal dans le dossier src lancer l'environnement de la simulation avec : 
python3 env.py

Dans un second terminal dans le dossier src lancer la display permettant d'agir sur l'environnement avec:
python3 display.py

A partir de maintenant vous pouvez regarder où en est la simulation, ajouter a votre guise des prey/predator, déclencher des sécheresses...
